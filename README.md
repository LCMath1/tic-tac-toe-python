# Tic-Tac-Toe

A simple command-line Tic-Tac-Toe game written in Python.

## About

This project is a two-player Tic-Tac-Toe game that runs in the terminal. Players take turns choosing a row and column to place their X or O.

I built this project to practice Python fundamentals, including functions, loops, conditionals, lists, recursion, and basic input validation.

## Features

* Two-player gameplay
* Choose whether X or O starts
* Detects winning moves
* Detects draws
* Prevents players from overwriting occupied squares
* Allows players to retry invalid moves
* Command-line interface

## How to Play

1. Run `main.py`.
2. Choose whether X or O will start.
3. On your turn, enter a row and column from 1 to 3.
4. The game continues until one player wins or the board is full.

## Example

```text
_ _ _
_ _ _
_ _ _

Welcome to Tic-Tac-Toe!
Who will start: X or O? X

X's turn:
Which column would you like to play in? (1-3) 2
Which row would you like to play in? (1-3) 2
_ _ _
_ X _
_ _ _
```
